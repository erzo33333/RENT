3. Функциональные требования
Все требования сформулированы относительно двух действующих лиц информационной системы, арендодателя и арендатора.
3.1. Управление объектами недвижимости
•	FR-L-1.1. Создание, редактирование, архивирование карточек квартир.
•	FR-L-1.2. Хранение атрибутов: адрес, площадь, количество комнат, этаж, кадастровый номер, фото/видео, планировка.
•	FR-L-1.3. Указание статуса: «свободна», «сдана», «на ремонте», «забронирована».
•	FR-L-1.4. Поиск и фильтрация квартир по параметрам.
•	FR-L-1.5. История изменений по объекту.
3.2. Учёт сведений о проживающих
•	FR-L-2.1. Приглашение арендатора в систему арендодателем.
•	FR-L-2.2. Список проживающих: ФИО, контакты, реквизиты документа (для внутреннего учёта).
•	FR-L-2.3. Связь «объект ↔ договор ↔ проживающий» внутри системы.
•	FR-L-2.4. История аренды по каждому объекту (все прошлые и текущие периоды).
•	FR-L-2.5. Заметки и внутренние пометки арендодателя о проживающих.
3.3. Управление договорами
•	FR-L-3.1. Создание договора из шаблона с автоподстановкой данных.
•	FR-L-3.2. Хранение скан-копий договоров и допсоглашений.
•	FR-L-3.3. Указание срока действия, даты начала/окончания, суммы аренды, депозита.
•	FR-L-3.4. Хранение истории изменений условий договора.
3.4. Учёт платежей
•	FR-L-4.1. Фиксация поступлений (аренда, депозит, коммунальные платежи).
•	FR-L-4.2. Фиксация расходов (ремонт, оплата коммунальных платежей).
•	FR-L-4.3. Отчёты по доходности каждого объекта и всех объектов в целом.
3.5. Учёт имущества
•	FR-L-5.1. Реестр имущества по каждой квартире (наименование, количество, состояние, фото).
•	FR-L-5.2. Формирование акта приёма-передачи при старте аренды.
•	FR-L-5.3. Формирование акта возврата при завершении аренды.
•	FR-L-5.4. Сравнение состояния «до/после» (фото, заметки).
•	FR-L-5.5. Учёт износа и необходимости замены.
3.6. Учёт показаний счётчиков
•	FR-L-6.1. Реестр счётчиков по объекту (тип, номер, дата поверки).
•	FR-L-6.2. Ввод показаний арендодателем.
•	FR-L-6.3. Автоматический расчёт потребления и стоимости.
•	FR-L-6.4. История показаний и графики потребления.
3.7. Уведомления и напоминания
•	FR-L-7.1. Настраиваемые напоминания: платежи, сроки договоров, показания счётчиков, плановые проверки.
•	FR-L-7.2. Все уведомления адресуются арендодателю на email.
3.8. Отчётность и аналитика
•	FR-L-8.1. Дашборд: загрузка объектов, доходность, задолженности.
•	FR-L-8.2. Отчёты по каждому объекту отдельно или всем вместе.
•	FR-L-8.3. Анализ доходов/расходов по периодам.
3.9. Пользователь и доступ
•	FR-L-9.1. Две роли — арендодатель (администратор системы) и арендатор.
•	FR-L-9.2. Разграничение прав доступа к данным.
•	FR-L-9.3. Арендодатель и арендатор имеют личный кабинет.
3.10. Интеграции и технические требования
•	FR-L-10.1. Веб-приложение (адаптивная вёрстка для работы с планшета и смартфона).
•	FR-L-10.2. Интеграция с банками (импорт выписок), SMS-шлюзами для напоминаний.
•	FR-L-10.3. Резервное копирование и защита персональных данных (152-ФЗ).

FR-T. Функции арендатора
•	FR-T-1. Регистрация в системе по приглашению арендодателя.
•	FR-T-2. Заполнение и редактирование личного профиля.
•	FR-T-3. Просмотр договора аренды и допсоглашений.
•	FR-T-4. Просмотр графика платежей и остатка депозита.
•	FR-T-5. Загрузка подтверждения оплаты.
•	FR-T-6. Ввод показаний счётчиков с фото-подтверждением.
•	FR-T-7. Просмотр истории показаний и начислений.
•	FR-T-8. Просмотр статуса заявок.
•	FR-T-9. Просмотр финального расчёта при выезде.
•	FR-T-10. Получение email-уведомлений о предстоящих платежах, необходимости отправить показания счётчиков и статусах заявок.
